# Tic Tac Toe - Monte Carlo AI

Un juego de Tic Tac Toe clásico implementado en Python con una Inteligencia Artificial avanzada basada en el algoritmo **Monte Carlo Tree Search (MCTS)**.

## Características
* **IA Inteligente:** Utiliza MCTS para simular miles de partidas y elegir el movimiento óptimo.
* **Interfaz Gráfica (GUI):** Desarrollada con `Tkinter`.
* **Modos de Juego:** - Humano vs IA (Monte Carlo).
  - Humano vs IA (Aleatoria).
  - Humano vs Humano.
* **Visualización:** Capacidad para abrir una ventana que muestra el árbol de decisiones del algoritmo.

## Requisitos
- Python 3.x
- `anytree`

## Instalación
1. Clona el repositorio:
   `git clone https://github.com/tu_usuario/tu_repo.git`
2. Instala las dependencias:
   `pip install -r requirements.txt`
3. Ejecuta el juego:
   `python Tik_tak_toe.py`
